Kerberos Practical Commands

1. Update System
sudo apt update
2. Install Kerberos Server
sudo apt install krb5-kdc krb5-admin-server krb5-config -y
3. Create Realm Database
sudo krb5_newrealm
4. Create Admin User
sudo kadmin.local -q "addprinc root/admin"
5. Give Admin Permission
sudo nano /etc/krb5kdc/kadm5.acl

Add:

root/admin@EXAMPLE.COM *
6. Restart Services
sudo systemctl restart krb5-kdc
sudo systemctl restart krb5-admin-server
7. Install Kerberos Client
sudo apt install krb5-user libpam-krb5 -y
8. Login / Get Ticket
kinit myuser
9. Check Ticket
klist
10. Logout
kdestroy


Viva One-Liners
Kerberos → Ticket-based authentication protocol.
KDC → Key Distribution Center.
AS → Authentication Server.
TGS → Ticket Granting Server.
TGT → Ticket Granting Ticket.
kinit → Get ticket.
klist → View ticket.
kdestroy → Delete ticket.
Realm → Administrative domain in Kerberos.
Advantage → Password is not sent over the network.
